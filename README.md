# Lector web — Los juegos del hambre

Lector estático construido a partir de la capa de texto del PDF proporcionado, sin OCR.

- 333 páginas.
- Texto extraído página por página.
- HTML + CSS + JavaScript puro.
- Fondo negro y tipografía grande.
- Animación 3D de hoja al avanzar y retroceder.
- Deslizamiento táctil y arrastre con mouse.
- Botones anterior/siguiente, ir a página, zoom y pantalla completa.
- Guarda página y zoom con localStorage.
- Diseño responsive para teléfonos, tablets y escritorio.
- No necesita backend, base de datos ni instalación.

## Uso
Abre `index.html` con Chrome, Edge, Firefox, Safari u otro navegador moderno.
